## 🌟 Overview

Cineflow Studio is a next-generation web application designed to streamline the entire movie production lifecycle. Built for producers, directors, financiers, and crew members, it replaces fragmented spreadsheets with a robust, centralized dashboard for real-time tracking of budgets, project phases, and ROI.

## ✨ Key Features

- **📊 Comprehensive Project Management**: Create, track, and manage all aspects of your film slate from pre-production to distribution.
- **🔐 Role-Based Workspaces**: Tailored, secure dashboards for Accountants, Crew, Managers, and Producers.
- **📈 Advanced Analytics & Reporting**: Gain valuable insights with integrated charts, forecasting, and data visualization.
- **💰 Finance & Budgeting**: Built-in tools for tracking expenses, managing multi-million dollar budgets, and estimating revenue/ROI.
- **🗓️ Crew Scheduling**: Intuitive interfaces to schedule crew members efficiently and manage daily call sheets.
- **📱 Responsive & Premium UI**: Designed with a stunning, cinematic interface that works flawlessly on desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing**: [TanStack Router](https://tanstack.com/router/latest)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **State Management**: [TanStack Query](https://tanstack.com/query/latest)
- **Charts**: [Recharts](https://recharts.org/)

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or bun

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd cineflow-studio
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   bun install
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   bun run dev
   ```

4. Build for production:
   ```bash
   npm run build
   # or
   bun run build
   ```

## Scripts

- `npm run dev`: Starts the Vite development server.
- `npm run build`: Builds the application for production.
- `npm run preview`: Previews the production build locally.
- `npm run lint`: Runs ESLint to check for code issues.
- `npm run format`: Formats code using Prettier.
